# 🚀 **QUICK START (5 MINUTES)**

</div>

### **Step 1️⃣: Clone Repository**
```bash
git clone https://github.com/ilham1421/booking_barber.git
cd booking_barber
```

### **Step 2️⃣: Install Dependencies**
```bash
npm install
# or pnpm install (faster!)
```

### **Step 3️⃣: Setup Environment**
Create `.env.local`:
```env
# 🗄️ Database
DATABASE_URL="postgresql://user:password@localhost:5432/booking_barber"

# 🔐 JWT Secret (generate: openssl rand -base64 32)
JWT_SECRET="your-secret-key-min-32-characters"

# 📧 Email Service
RESEND_API_KEY="re_your_api_key"

# 🔑 Auth
NEXTAUTH_SECRET="another-secret"
```

### **Step 4️⃣: Database Setup**
```bash
# Run migrations
npx prisma migrate dev --name init

# Seed demo data (optional)
npm run seed
```

### **Step 5️⃣: Start Development**
```bash
npm run dev
```

🎉 **Live at** [http://localhost:3000](http://localhost:3000)

```
│        ADMIN             │

            │
            ├──────────┐
```

<summary><b>📊 Data Models</b></summary>

```typescript
id • nameId/nameEn • descId/descEn • price (Rp) 
duration (min) • imageUrl • isActive • order
```

**Booking** - Customer appointments
```typescript
id • bookingCode (REF-XXXX) • customerName/Email/Phone
serviceId • bookingDate • timeSlot • status • notes
status: PENDING | CONFIRMED | CANCELLED | COMPLETED
```

**Schedule** - Operating hours
```typescript
dayOfWeek (0-6) • openTime (HH:MM) • closeTime • isOpen
```

**Admin** - User accounts
```typescript
id • username (unique) • passwordHash (bcrypt)
```

## 🔌 API Reference

All endpoints return JSON. Base URL: `/api`

### **Authentication**
```http
POST /admin/login
  → Returns: { token: string, admin: { id, username } }
  → Body: { username: string, password: string }
  
POST /admin/logout
  → Returns: { success: true }
  → Headers: { Authorization: "Bearer <token>" }
```

### **Bookings (CRUD)**
```http
GET /bookings?page=1&limit=10&status=PENDING
  → Returns: { bookings: Booking[], total: number }
  
POST /bookings
  → Returns: { booking: Booking, bookingCode: string }
  → Body: { customerName, customerEmail, customerPhone, serviceId, bookingDate, timeSlot }
  
GET /bookings/[id]
  → Returns: { booking: Booking }
  
PATCH /bookings/[id]
  → Returns: { booking: Booking }
  → Body: { status: BookingStatus, notes?: string }
  
DELETE /bookings/[id]
  → Returns: { success: true, message: string }
```

### **Services**
```http
GET /services?active=true
  → Returns: { services: Service[] }
  
POST /services (admin only)
  → Returns: { service: Service }
  → Body: { nameId, nameEn, descId, descEn, price, duration, imageUrl? }
  
PATCH /services/[id]
  → Returns: { service: Service }
  → Body: { Partial<Service> }
  
DELETE /services/[id]
  → Returns: { success: true }
```

### **Schedule**
```http
GET /schedule/slots?date=2026-05-22&serviceId=[id]
  → Returns: { availableSlots: string[] }
  → Example response: { availableSlots: ["09:00", "10:00", "11:00"] }
```

## 🔐 Authentication & Security

### **Login Flow** 🔑
```
Client sends credentials
         ↓
Server validates against Admin model
         ↓
Password compared with bcrypt hash
         ↓
JWT token generated (HS256 algorithm)
         ↓
Token returned to client (valid 7 days)
         ↓
Client includes token in Authorization header
         ↓
Server verifies token with secret
```

### **What We Protect** 🛡️
✅ Admin login endpoints (rate-limited concept)
✅ Booking creation (validates input with Zod)
✅ Service management (admin-only routes)
✅ Password hashing (bcryptjs with 10 salt rounds)
✅ JWT secrets (never exposed in client)
✅ Environment variables (loaded from .env.local only)

## 🆘 Troubleshooting

### **Port 3000 already in use?**
```bash
# Windows
netstat -ano | findstr :3000
# Then kill the process

# macOS/Linux
lsof -i :3000
kill -9 <PID>
```

### **Database connection error?**
- Check `.env.local` has correct `DATABASE_URL`
- Ensure PostgreSQL is running
- Verify credentials are correct

### **Migrations failing?**
```bash
# Reset migrations (development only!)
npx prisma migrate reset

# Then seed again
npm run seed
```

### **Styles not showing?**
```bash
# Rebuild Tailwind
npm run dev

# If still broken, clear .next cache
rm -rf .next
npm run build
```
